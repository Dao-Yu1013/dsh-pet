# 代码是怎么长的

这个项目没有用 Gradle，也没有分层架构图那种整洁的东西。它是从一个小挂件一点点加出来的，所以结构上更像"一个 Activity 带着一堆模块"。

这篇只讲主线，细节看源码。

## 三层

**WebView 前端**

`app/src/main/assets/ui/` 下是 `index.html`、`app.js`、`app.css`。底部五个 tab：首页、聊天、动作、陪伴、设置，其余页面都在 `app.js` 里用 if/else 画出来。状态全在前端，刷新页面会重新问原生要数据。

**Java 层**

`com.dshpet.android` 下 116 个类。按职责大致分：

| 范围 | 主要类 |
| --- | --- |
| 入口和桥 | `MainAct`、`App`、`WebUI`、`Secure`、`Cfg` |
| 聊天和提示词 | `Brain`、`Ai`、`Nlu`、`IntentRouter`、`ChatBox` |
| 记忆、人设、日记 | `Mem`、`MemState`、`Persona`、`PersonaAuto`、`Diary`、`Intimacy` |
| 桌宠和前台服务 | `PetSvc`、`Pet`、`Live2DModel`、`Live2DRenderer`、`Bubble` |
| 手机能力 | `A11y`、`MobileActionExecutor`、`Notify`、`Usage`、`Geo` |
| 通道 | `QQOneBot`、`QQGroupChat`、`AstrBotBridge`、`DshBoxBridge`、`ComfyUi` |
| 内容 | `Books`、`ReaderFlow`、`Sticker`、`Music`、`Ledger` |
| 插件 | `PluginGen`、`PluginDexCompiler`、`DexPlugins`、`Plugins` |

**原生层**

`app/src/main/cpp/dshcore.cpp`，只做两件事：校验安装包签名，以及在前端加密成 `sec.bin` 之后解出明文页面。没有别的重型 JNI 逻辑。

## 前端怎么调原生

前端统一走一个方法：

```js
Dsh.call(id, "chat", JSON.stringify(args))
```

原生侧 `MainAct.Bridge` 挂着 `@JavascriptInterface`，收到之后交给 `MainAct.dispatch`。dispatch 按方法名分到四个执行器：UI 线程、普通 worker、slowWorker、astrbotWorker。聊天的超时给到 210 秒，其余 90 秒。

结果有两条路回前端：`__nativeResult` 是调用的返回值，`__event` 是主动推送，比如流式输出、新消息、状态变化。前端只监听，不轮询。

加新功能时最容易漏的是三处：dispatch 里要有 case，proguard 要保留桥方法名，前端要处理失败和超时。

## 一次聊天发生了什么

1. 你发一句话，`MainAct` 先做一层路由：是语音意图、贴纸、屏幕提问，还是普通聊天。
2. 普通聊天进 `Brain.chat`。它开始拼系统提示词，顺序大概是当前时间和时段、人设卡、你的资料、召回的长期记忆、相关的最近日记、亲密度和情绪、最近几条历史。
3. `Ai` 拿这个请求打 OpenAI 兼容接口，SSE 流式收，边收边往前端推，前端做打字机效果。
4. 收完先清洗：去掉模型复读的时间标记、代码围栏，然后按完整句子切成几条气泡。
5. `Data.chatAppend` 追加进 `chat.jsonl`。
6. 如果开了自动记忆，后台异步跑一次提炼，只处理游标之后你说的话，攒够六条才跑。
7. 如果开了远端智能体，这一步改走 `AstrBotBridge`，失败再回退本地模型。

主动搭话是另一条路：`PetSvc` 里的调度定时醒来，`Brain.proactive` 结合时间、状态、你最近在用什么应用判断要不要开口。开不开、多久一次，都在设置里。

## 记忆

存 `files/S-G/memories.json`，一个 JSON 数组，一条一个对象。

一条记忆里有正文、你的原话引用、来源、置信度、状态、有效期、被佐证过几次、标签，还有召回统计。敏感词（密码、证件、卡号之类）会被标成 secret，不往提示词里放。

写入有四种：

- 你明确说"记住"，`Brain.explicitRemember` 直接入库，置信度 0.95，置顶。
- 聊天里自动提炼，模型只允许输出 JSON 操作指令，代码还要逐条核对引用是不是你真说过。矛盾的新信息走"取代"，不覆盖。
- 手动添加。
- 备份导入时合并。

读取分两块：偏好类会拼进系统提示词，但注明"只在能帮上忙的时候提"；相关记忆按当前话题召回几条，被用到的会累加召回次数。

识海的数据不落盘，每次由 `Mem.graphData` 从 memories.json 现算，最多 8000 个节点、14400 条连线，只有共享标签才算关系，不按时间硬连。

## 日记

`Diary` 的设计前提是"可以不写"。定时机会每六小时最多考虑一次，今天没聊过天、没观察到东西，就不写。模型也可以返回 `[[不写]]`。

写的时候有两种视角：聊得多就用当天对话压成实录；聊得少就只能从"他在用什么应用 + 屏幕上的字"猜，语气要求带"好像、大概"。

成稿是一行 JSON，追加进 `diary.jsonl`，带上日期、亲密度阶段和来源类型。

## 人设和性格

人设存在 `persona.json`：名字、开场白、说话风格、边界、小习惯。读写都走同一把锁，防止自动演化和手动编辑打架。

性格演化的节流比较狠：每天最多检查一次，真正重写至少隔七天，还要求观察够三天、最近聊够八条。模型只能改风格、开场白、边界、习惯这四项，关系、原型、语调这三样是底色，不许动。改完还要过长度区间和禁用词，通不过就丢弃。

## QQ

私聊和群聊是两条完全不同的路。

私聊走 `QQOneBot`：收到消息先写进 `chat.jsonl`，然后调 `Brain.chatExternal`，跟聊天页用的是同一个大脑、同一套记忆。QQ 里说"记住"也照样入库。

群聊走 `QQGroupChat`：单独维护每个群的历史，不写你的聊天记录，也不进长期记忆。空闲半小时后，用本机模型把群聊压成最多六条摘要，原文清掉。群聊可以挂独立人设，也可以单独开 AstrBot 模式，但那时也不会读你的私人记忆。

同一个 QQ 号如果同时被桌宠和 AstrBot 原生适配器连着，会出现两边都回一条的情况。设置里有"让位"开关，检测到外部应答者就会闭嘴。

## AstrBot 和手机工具

`AstrBotBridge` 走 AstrBot 的 OpenAPI `/api/v1/chat`，Bearer Key，SSE 或 JSON 都能解析。没配模型这类致命错误会被识别成配置问题，不会当成她的话显示出来。

手机工具是另一套：桌宠向 AstrBot 里的桥接插件开一个设备会话，模型才有权调用 `dsh_mobile_action`。动作只有读屏、开应用、按文字点击、上下滑、返回这几种，全部由 `MobileActionExecutor` 通过无障碍执行，执行前要你在浮窗上确认。

## 插件

插件分两种：

- 配置型或 JS 型，导入后默认关闭，先过清单、入口、脚本大小、域名白名单检查。JS 会在一个断网的 WebView 沙箱里试跑一次入口，只验证"能不能跑起来"。
- AI 生成的 Java 插件：先出草稿，你回复"装上"之后才编译。`PluginDexCompiler` 用 ECJ 编译，D8 转 DEX，`DexPlugins` 在宿主进程里加载。

第二种没有任何隔离，插件和应用同进程、同权限。装之前想清楚来源。

## 数据都在哪

全部在应用私有目录 `files/S-G`，写入走 `Sg.java`：先写临时文件，fsync，再原子替换，避免写到一半断电把文件弄坏。

| 文件 | 内容 |
| --- | --- |
| `config.json` | 所有设置 |
| `persona.json` | 人设 |
| `profile.json` | 你的资料 |
| `chat.jsonl` | 聊天和 QQ 私聊原文 |
| `memories.json` | 长期记忆 |
| `mem_audit.jsonl` | 记忆操作审计 |
| `diary.jsonl` | 日记 |
| `her_words.jsonl` | 她主动说过的话 |
| `mood.jsonl` | 情绪记录 |
| `stats.json` | 互动统计和亲密度 |
| `reminders.json` / `tasks.json` | 提醒和任务 |
| `books.json` / `reader.json` / `clips.json` / `ledger.jsonl` | 书架、阅读进度、收藏、记账 |

导出备份就是把整个目录打包。

## 加固和签名

正式包会把九个前端文件加密成一个 `sec.bin`，运行时由 `WebUI` 解到私有目录再加载。密钥派生写在 `build.ps1` 和 `dshcore.cpp` 里，两边必须一致，改一处就要改另一处。

`dshcore.cpp` 里还写死了一份证书指纹。APK 签名对不上，应用启动时就会报"签名校验不通过"。自己重新签名的话，必须把 `kCert` 换成你的证书指纹，否则装了也打不开。`-Fast` 构建会跳过前端加密，用来排障。

这套东西挡不住真正想看代码的人，只是提高一点门槛。真要逆向，DEX 和 JS 都在包里。

## 为什么没有 Gradle

一开始只是个小实验，直接 javac 加 aapt2 就够了。后来功能变多，构建步骤越来越长，但每一步都能在 `build.ps1` 里看清楚，改起来也直接，就一直没迁。代价是换电脑要自己装工具链，路径也得对上。构建细节见 [构建.md](构建.md)。
