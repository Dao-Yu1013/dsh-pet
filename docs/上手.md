# 上手

这篇按第一次使用的顺序写。每一步都能跳过，但跳过之后对应功能就用不了。

## 装上去

APK 支持 Android 9 及以上。用文件管理器打开安装包，系统可能会提示"未知来源"，允许一次就行。

安装完第一次打开，首页会显示一行"还差几项设置"，这不是报错，是提醒。点"去检查"会跳到权限体检页。

## 给权限

桌宠不需要一次性把权限全给了，按用途分开：

- **悬浮窗**：不给的话点"放出来"也没反应，她就只能待在应用里面。
- **无障碍**：用于读屏、广告跳过、自动点按。系统设置里叫"无障碍服务"，找到 DSH 桌宠打开。
- **通知读取**：通知摘要、自动记账、歌词都靠它。
- **使用情况访问**：统计应用时长要用，这个入口藏得比较深，一般在"设置 → 应用 → 特殊权限"。
- **定位**：位置提醒和天气要用。后台定位还要单独选"始终允许"。
- **麦克风**：按住说话才需要。
- **日历**：想让提醒中心汇总日程才需要。

权限体检页会标出哪些已经给了、哪些还差。少给几项也能用，只是对应功能会提示你缺什么。

## 配模型

进"设置 → 智能核心"。三个字段：

- **Base URL**：OpenAI 兼容地址，一般以 `/v1` 结尾，填服务商文档给的那个。
- **API Key**：自己的 key，只存在手机本地设置里。
- **模型**：填模型名，比如 `deepseek-chat` 之类。

保存后回聊天页说句话试试。报错会直接把中文原因写在气泡里，不会甩一段 HTTP 响应给你。

看图要另配视觉模型；视频理解要配 Gemini 的 key；图像生成可以选云端接口，也可以接电脑上的 ComfyUI，填局域网 IP 和导出的 API 格式工作流 JSON。这部分在设置里都有对应入口。

## 让她出来

回首页点"放出来"。第一次会弹悬浮窗授权。

桌宠卡片里有大小、透明度、点击音效、锁定位置几个开关。长按浮窗也能打开这些设置。"换装"可以预览和切换皮肤，也能导入皮肤包。

如果她过一会儿不见了，多半是被系统杀了。把电池优化关掉，厂商的自启动管理里也放行一下。

## 记忆和日记

这两样都是自动的，不用手动管，但可以看：

- **记忆页**：能搜索、筛选、手动加一条，也能删。顶部有"打开识海"，进去是一张可旋转的星图，每条记忆是一个亮点。
- **日记页**：能看到她写过什么。她写不写由她自己判断，没有"必须每天一篇"的设定。
- **我们的关系**：亲密度、相处天数、性格变化记录。

"清空全部记忆"会连她说过的话的索引一起清掉，聊天记录本身要去聊天页单独清。

## 接 QQ

前提是你自己有一个跑着的 NapCat。手机和电脑都行，电脑上更省事。

1. 进"设置 → 个人 QQ 连接"，页面上有"第一次设置？看大白话连接教程"，按你的情况选"电脑—手机"或"手机—手机"。
2. NapCat 里开正向 WebSocket，默认端口 3001，路径 `/`。设了 token 就填一样的 token。
3. 桌宠里填 NapCat 所在设备的地址。同一局域网填那个设备的内网 IP，不要填 `127.0.0.1`，除非两个程序在同一台手机上。
4. 连接状态显示"已连接"之后，先用自己的 QQ 发一条私聊试试。

私聊和桌宠聊天是同一套记忆，群里说的话不会进你的私人记忆。群聊默认只在被 @ 时回，也可以开自由参与。群聊还能挂独立的人设卡，跟私聊分开。

## 接 AstrBot

这一步是可选的。接了以后，聊天交给远端的 AstrBot 处理，本地模型作为兜底。

1. AstrBot 的 WebUI 里"设置 → OpenAPI"建一个 Key，勾 `chat` 和 `plugin`。
2. 桌宠"功能中心 → 插件"填地址和 Key。局域网用 `http://192.168.x.x:6185`，公网必须 HTTPS。
3. 想让她操作手机，就在插件页导出"DSH 手机本地工具桥"装到 AstrBot，然后在桌宠里打开"手机工具"。

打开手机工具之后，AstrBot 可以让她读屏、打开应用、点文字、滑动、返回，但：

- 每个动作都会在桌宠浮窗上弹确认，25 秒内不点就作废。
- 一轮最多 6 个动作，群聊里不触发。
- 读屏只拿当前前台应用看得见的文字，不碰密码框，也不上传整张截图以外的原始界面。

不放心就关掉，不影响普通聊天。

## 备份和换机

"设置 → S-G 数据"里可以导出整包，得到的是一个压缩文件，里面有记忆、聊天、人设、书架、插件配置。换手机时先在新手机装好，再导入。

导入会覆盖本地数据，操作前建议先导出一份当前的。云同步走 WebDAV，需要你自己的服务器地址和账号。

重装应用不会自动保留数据，签名变了也装不上去，升级前先确认安装包是同一个签名。

先看 [常见问题](常见问题.md)。还是不行的话，开发者模式里可以导出诊断信息，里面有版本、配置路径和最近的错误记录，发 issue 时带上会省很多事。
