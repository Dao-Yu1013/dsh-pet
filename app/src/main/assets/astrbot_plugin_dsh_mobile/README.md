# DSH Android 手机工具桥（AstrBot 插件）

此插件只在 AstrBot 收到 DSH 的一轮远端聊天时，向模型提供 `dsh_mobile_action` 工具。手机在该聊天期间短时 HTTP 长轮询；每个动作都要桌宠界面前台逐次确认。会话结束后手机停止轮询并关闭临时桥接会话。

## 安装

1. 在桌宠“功能中心 → 插件”点“导出配套 AstrBot 插件”，选择保存位置，把 ZIP 传到运行 AstrBot 的电脑并解压。
2. 将 ZIP 中的 `astrbot_plugin_dsh_mobile` 文件夹放到 AstrBot 数据目录 `data/plugins/`。
3. 在 AstrBot WebUI 的插件页面重载插件；确认插件已加载，并在当前配置文件/人格中允许 `dsh_mobile_action` 工具。
4. 创建同时有 `chat`、`plugin` scope 的 OpenAPI Key；手机和 AstrBot 必须能通过已配置的地址相互访问。
5. 手机连接 AstrBot、启用远端智能体、检查桥接，再单独开启手机工具。手机端每一轮聊天期间才会打开临时会话。

插件不声明额外 Python 依赖。它只注册 AstrBot 插件工具和受 API Key 保护的插件 Web API 路由。

## 开放的动作

- `read_screen`：只读取当前前台应用提供的可见文字，不采集控件坐标或密码字段。内容会返回 AstrBot，可能包含私人信息。
- `open_app`：按 Android 包名打开已安装应用。
- `tap_text`：在指定前台应用中点击唯一匹配的精确可见文字；不接受坐标。
- `swipe`：只支持本机固定距离的上滑/下滑，并核对前台应用。
- `back`：当前应用仍匹配时执行一次系统返回。

手机端只接受以上固定动作，不接受 Shell、Python、JavaScript、DEX、任意坐标、任意 Intent 或原生插件安装。每一步都要用户在桌宠浮窗确认；执行前会核对目标应用和无障碍状态，用户拒绝、目标应用变化、无障碍不可用或超时都会取消操作。每轮最多执行 6 个动作。

群聊不转发到 AstrBot，也不允许调用此手机工具。屏幕文字是非可信页面内容，插件会在返回值中明确标记并提醒模型不要把它当作指令。

## 网络与省电

手机不常驻 WebSocket 或后台轮询。只有开启手机工具并发送一轮远端聊天时，才打开一个临时会话并发起最长 20 秒的 HTTP 长轮询；聊天完成或关闭工具后即停止。网络使用与 AstrBot OpenAPI 相同的地址、HTTPS/LAN 规则和 API Key。公网部署仍必须使用有效 HTTPS，并且不要开放不受信任的 AstrBot 服务。

## 兼容性

`metadata.yaml` 声明 AstrBot `>=4.18,<5`。实际可用性还取决于插件已加载、人格允许工具、模型支持工具调用、手机端启用无障碍，以及用户确认。安装插件不表示手机控制已连通；请在桌宠插件页检查桥接状态。
