# DSH 桌宠功能知识库

> 文档核对日期：2026-11-03。当前源码目标为 2.6.2 / versionCode 106；识海最多展示 8,000 条记忆、10 条已观察经历和 14,400 条真实关联，支持 dsh-chain 风格点选详情、全向旋转、放大，以及向分类星团汇聚的开场动画。构建与设备验证状态以项目接手说明中的最新记录为准。

## 远端 AstrBot 智能体与插件市场
关键词：AstrBot|智能体|AstrBot 插件市场|远端插件|记忆同步|OpenAPI Key
在“功能中心 → 插件”连接电脑或服务器上的 AstrBot：填入 HTTPS 服务地址，或仅用于可信局域网的 HTTP 地址；在 AstrBot“设置 → OpenAPI”创建具有 `chat`、`plugin` 权限的 Key。Key 保存在桌宠应用私有设置中，不回传给 Web 页面；更换服务地址时需重新填写新服务的 Key，并重新确认 Agent 共享。首次打开此页会清除旧版遗留的未运行 AstrBot 运行层缓存和旧回环 Key，不影响聊天或记忆。公网务必使用 HTTPS；不要把 AstrBot 服务或 OneBot 端口直接暴露在公网。桌宠不内置、不启动 PRoot/Python/AstrBot，不维持常驻 AstrBot 连接或后台轮询。

插件页“第一次连接？看完整上手教程”可查看电脑端 AstrBot Launcher 安装、模型配置、局域网访问、API Key scope 和手机连接方法。模型配置顺序：先在“模型提供商 → 对话 → 新增”添加服务并启用模型，再到“配置文件 → AI → 模型”选择对话模型并保存，先确认 AstrBot 自带聊天能回复。基本连接顺序：手机和电脑连同一可信 Wi-Fi → AstrBot 允许局域网访问且防火墙仅向专用网络开放 TCP 6185 → 创建带 `chat`、`plugin` scope 的 Key → 手机填写电脑 Wi-Fi IPv4 地址和 Key。不要使用 `127.0.0.1`。跨公网访问须使用有效 HTTPS 域名。官方指南：Launcher https://docs.astrbot.app/deploy/astrbot/launcher.html；模型接入 https://docs.astrbot.app/providers/start.html；OpenAPI https://docs.astrbot.app/dev/openapi.html。

连接成功后，桌宠可读取远端 AstrBot 插件市场与安装状态。手机页面负责浏览、确认和发起安装；插件代码、Python 依赖和运行权限都属于远端 AstrBot 服务。安装前会显示来源、版本、平台/依赖等市场字段并要求确认；安装后依据 AstrBot 返回的已安装/失败状态显示结果。AstrBot 接口未提供明确加载状态时，桌宠不会宣称插件已加载。DSH 原生插件和 AstrBot Python 插件是两种独立格式。

开启“让桌宠和 QQ 私聊共用远端智能体”后，桌宠普通文本与经本应用 OneBot 连接的 QQ 私聊使用同一稳定 AstrBot 用户和会话；本地记忆摘要或人设变化时不会新开会话；下一轮会把更新后限长的记忆与角色设定附加到同一稳定会话。最多同步 12 条、2400 字的记忆摘要，不上传整份本地聊天记录。旧 AstrBot 会话不会被手机远程删除，仍按服务端保留策略存储。选择远端智能体即表示这些摘要和文字会发送到你配置的 AstrBot 服务。桌宠聊天中的图片、文件和屏幕提问仍走手机现有流程，不自动上传。经 NapCat 收到的 QQ 私聊图片或带可读链接的表情由手机视觉模型识别，并保存到本机聊天；图片链接缺失或读取失败时会明确说明，不会按纯文字猜。QQ 回复目前通过 OneBot 只发送文字；本地表情标记只会在 DSH 聊天显示，不代表图片已发到 QQ。QQ 群聊目前仍只处理文字和图片提示，不把图片送给视觉模型。另可在插件页导出并安装“DSH 手机本地工具桥”，然后显式开启“手机工具”：仅在每一轮远端聊天期间短时建立 HTTP 长轮询；读取屏幕只采集当前前台应用可见的文字，不包含控件坐标或密码字段，并会发送给 AstrBot。打开应用、精确点击文字、上下滑动和返回均需桌宠浮窗逐次确认；执行前会核对应用和无障碍状态。手机只执行固定白名单动作，不下载或运行远端代码；群聊不会触发手机工具。QQ 群聊默认使用本机群聊模型；也可在 QQ 设置中单独开启“群聊使用 AstrBot 插件”，此时群文字会发往配置的 AstrBot Agent，使用独立于私聊和其他群的用户名、会话及群专属摘要，不读取或同步主人的私人记忆。只有能由 AstrBot 对话 Agent 调用的已安装插件/工具适用；依赖原生 QQ 群事件或 QQ 平台发送能力的插件不会触发。开启前请确认信任该群和远端服务；群内容会发送至你配置的 AstrBot。若关闭连接时群聊回复尚在生成，会等该请求回调后再收尾。应用进程重启并恢复 QQ 连接时会按落盘时间恢复计时；Doze 或进程被系统回收可能延迟总结。摘要仅保留有用话题、有趣事件或待核实的新知识，最多保留 6 条；不会把整段群聊写进个人长期记忆。没有可用本机聊天模型或摘要调用失败时，原始消息仍会清除且无法生成摘要。

远端通信按需发起 HTTP 请求：打开插件页不会自动联网，聊天、搜索市场、安装或手动检查时才连接；手机工具关闭时没有 AstrBot 常驻 WebSocket、轮询、Python 进程或后台服务。手机工具开启后，仅在一轮 Agent 聊天期间做最多 20 秒的 HTTP 长轮询；聊天结束、关闭手机工具或 Agent 后即停止。QQ 长连接只在用户启用个人 QQ 连接时运行；NapCat 没有消息或协议 ping 时，手机约每 2 分钟做一次低频连接探测。远端聊天/插件能力依赖服务在线、API Key scope、网络和 AstrBot/插件自身兼容性；普通图片和文件尚未加入远端会话，不能说所有 AstrBot 插件都兼容。

本说明用于 AI 回答用户关于本应用的使用问题。以本文件对应的当前界面与源码实现为准；权限、API、网络、系统版本和厂商后台限制会影响实际可用性。只有功能代码和必要授权都存在时，才能说功能可用。没有操作回执时，不要说已经替用户打开、点击、读取或保存。

## 导航与首页
关键词：首页|底部导航|功能中心|首页卡片|快捷入口
主导航为“首页、聊天、动作、陪伴、设置”。首页有桌宠开关、角色信息、快捷卡片、待办和通知摘要；功能中心集中入口可搜索、收藏和查看最近使用。首次人设/关系表单未完成时，可在首页继续填写。

## 聊天、输入框与消息
关键词：聊天|输入框|加号|纸飞机|消息|引用|复制|标记|分段
聊天页支持文字和按住说话。松开说话后会给手机语音识别服务最多 10 秒返回最终文字，并保留识别器已经给出的中间结果；若手机没有返回文字，会说明检查麦克风权限和系统语音识别服务，不再立即以“没听清”结束。具体识别能力仍取决于手机当前启用的语音识别服务、网络和麦克风状态。输入为空时右侧按钮为加号，输入文字或附加文件/图片后显示纸飞机发送。加号菜单含相册、拍照、文件和表情包；笑脸按钮用于挑选并发送已有表情，不带上传入口。发送后，图片/文件预览会从输入栏清除，附件仍保留在已发送消息中。切到其他页面再返回聊天时会保留已有气泡和已解码的表情图片，刷新记录也会复用内容未变的气泡，以减少闪烁。聊天标题横幅右侧的折叠按钮可收起标题和说明，顶部会保留一条“和她聊聊 / 展开”窄栏；再次点击可展开，状态会记在本机。长按消息会在消息附近显示“引用、复制、标记为重要时刻”操作。选择引用后，输入区上方出现“名字：内容”的引用条，不会把旧消息塞进输入文字；发送时引用作为独立卡片保留在新消息中，并作为上下文交给 AI。AI 的长回复按完整句拆成多条消息，句内停顿不拆；拆分数量由回复语义决定。

首页问候语上的名字可点击进入“我的资料”，更换用户头像和聊天显示名字。保存后用户头像/名字同步到聊天记录显示，问候语按当前时段显示早上好、中午好、下午好或晚上好。该名字是用户自己的资料名，桌宠能看到它，但桌宠仍使用自己的人设名字，并自行决定如何称呼用户。

## 图片与文件附件
关键词：图片|相册|拍照|文件|附件|文档|上传|TXT|Word|Excel|PPT|PDF
聊天附件从加号选择。图片解码或视觉请求组装失败时会明确提示，这次不会悄悄按纯文字发送；图片需要设置中已配置且支持视觉输入的模型。AI 若回复“没收到图片/只有文字没有图”等否认语，应用会拦下并改为诚实说明识图未成功，避免把否认说成图片事实。文件正文由本机提取后交给聊天模型，常见可提取格式包括 TXT、MD、CSV、JSON、XML、HTML、RTF、DOCX、XLSX、PPTX、ODT、ODS、ODP；应用不设置单文件字节上限，实际上传仍受手机可用存储空间约束。每轮正文最多向聊天模型提供前 10 万字，超出部分暂不进入本轮上下文；这不是文件上传限制。原件保存在应用私有 S-G 目录，7 天后删除，聊天中保留一句话摘要和文件记录。PDF 及旧版 DOC/XLS/PPT 当前不做正文提取。

聊天加号里的“视频”可选择本地视频。发送时，应用把整段原始视频上传到 Google Gemini 视频理解服务，覆盖整个时间线并连同音轨分析；应用不自行抽取关键帧代替视频。Gemini 会自行采样视频画面（默认约每秒一帧）并处理音频，因此这是整段视频理解，不保证识别每一帧或极快闪过的细节。需要先在“设置 → 智能核心 → 完整视频理解”配置 Gemini API Key 和支持视频理解的模型。分析完成后应用会请求删除云端临时文件；若网络中断导致删除请求未送达，Gemini Files API 会在 48 小时后自动清理。视频在本机临时保存 7 天。视频上传需要网络；文件大小、时长、格式、额度和处理时长受 Gemini 服务及模型限制，应用本身不设视频字节上限。

## AI 长文与代码文件
关键词：长文|超长文本|写文章|写代码|MD|TXT|JAR|下载|复制全文
最终答复正文超过 1000 个字符，或答复涉及代码/程序（不论长短）时，回复会保存为可展开的文档卡片，可复制全文并通过系统保存位置下载 MD、TXT 或 JAR；普通日常答复仍按完整句子显示为气泡。JAR 是含源码/说明的 ZIP 归档，不是可直接运行或安装的程序。文档正文保存在应用私有 S-G 目录 7 天，到期后清理正文和导出副本，只保留一句话摘要作为长期记忆；卡片仍显示摘要。单份正文最多 2 MB；实际生成长度还受已配置模型和服务商的单次输出上限影响，应用不能绕过该上限；模型触及单次输出上限时不归档不完整内容。

## AI、模型、天气与实时推荐
关键词：模型|DeepSeek|API Key|视觉模型|天气|出行|附近|推荐|联网
普通对话由“设置 → 智能核心”中配置的聊天模型提供；看图需要另配视觉模型。模型服务不可用、额度不足、Key/权限错误、限流或网络超时时，聊天会显示对应的中文原因和下一步建议，不把原始 HTTP 响应、JSON 或堆栈直接塞进气泡。天气问答调用 Open-Meteo 和定位结果；失败时须说明真实原因。带伞判断优先参考当前天气和未来 12 小时逐小时预报，不应把已过去时段或数天后的降雨说成马上要下雨。“提醒我带伞”若没有具体时间，会加入提醒清单并说明尚未设置响铃时间，不会虚构定时通知。出游规划会先查询可用天气，再生成安排。附近店铺/商品/游玩推荐目前没有接入商家搜索数据时，只能结合用户记忆给选择思路，不能捏造店名、评分、库存、营业状态或价格，也不能说已经实时搜索。

图像生成可选云端 OpenAI 兼容接口或电脑上的 ComfyUI。使用 ComfyUI 时，在“设置 → 智能核心 → 图像生成”选择 ComfyUI，填电脑局域网 IP 和端口（默认 8188），并导入或粘贴 ComfyUI 导出的 API 格式工作流 JSON；普通画布工作流不能直接提交。手机和电脑需能互相访问，ComfyUI 默认只监听本机，须开启局域网监听（例如 `--listen 0.0.0.0`）。正向提示词节点 ID 通常会自动识别；复杂工作流可手动填一个或多个节点 ID。想保留固定画风词时，可在工作流正向提示词里放入 `{{prompt}}` 占位符。生成任务由 ComfyUI 排队执行，完成后图片会保存到桌宠贴图库并在聊天中显示。局域网服务不要暴露到公网。

每轮对话会附设备本地日期、时刻和时段；模型看到的近期聊天、她自己说过的话、长期记忆和承诺会附实际发生或确认时间。跨日后，昨晚的晚安、困倦等只作为历史内容，不应被当成现在仍在发生。QQ 私聊和群聊也会附本地当前时间；群聊近期历史和摘要生成会保留时间，群记忆摘要标注整理日期。旧版群记录没有时间戳时不会补造。模型仍可能判断失误；本功能尚未手机验证。

## 书架与内置阅读器
关键词：阅读书架|书架|阅读|读书|小说|EPUB|TXT|PDF|笔记|目录|朗读
入口为“功能中心 → 阅读书架”。可导入 TXT、EPUB、PDF、MOBI、AZW3 等书籍、整理书架、打开正文、目录跳章、翻页、记进度、做笔记/书签/划线及使用朗读。聊天里的 ReaderFlow 会读取书架、列出书名，让用户按书名或序号选择，并打开对应书籍；随后从上次阅读章节取出实际正文交给聊天模型阅读，生成一条章节心得，保存在读书笔记和本地读书记忆中，之后可按书名/读书话题回忆。当前每次选书只自动阅读上次位置的一章，不代表读完整本书或自动翻完整书。PDF 是渲染页面，不能当作已提取文字；没有读到正文或模型总结失败时不会记成已读，会如实记失败。
翻页默认使用轻柔平移；设置里仍可选完整 3D 仿真翻页、淡入或无动画。横向滑动和左右点按都会翻一页。PDF 只在内存保留当前页附近最多 3 页；页面渲染失败会显示原因并提供重试。
TXT、EPUB、PDF 是主要阅读格式；MOBI/AZW3 受文件压缩方式影响，部分文件会提示暂不支持。PDF 是页面图像渲染，不会提取扫描页或正文文本。

## 表情包
关键词：表情包|笑脸|贴图|表情|上传表情|管理表情
发送：聊天输入框笑脸按钮打开表情选择面板。管理：点加号，再点“表情包”，可使用原功能中心表情包管理界面，包括导入、识别、命名、场景编辑、替换和删除。用户明确表达希望多用表情时，应用记录这一偏好；具体发送仍由聊天语境决定。用户明确要求发送时，应用会校验本地图片文件并生成可渲染标记；“快点”“表情呢”“没看到”等短追问会在近期请求尚未完成时继承原来的本地/联网来源要求。联网搜索仅在图片下载并保存成功后才显示图片；失败或部分成功会说明实际结果，不会把“准备发送”当成已经发送。图片识别依赖视觉模型。桌宠主动即兴也可从本地已审核且图片可读取的表情中挑选；不会把尚未下载的网上图片说成已经发出。浮窗聊天框的笑脸按钮可选本地表情并发送，原图优先交给视觉模型识别，名字和场景说明只作辅助；识图失败会明确说明。

## 个人 QQ 连接
关键词：QQ|个人 QQ|NapCat|OneBot|QQ 私聊|连接 QQ
入口为“设置 → 个人 QQ 连接”；点“第一次设置？看大白话连接教程”可查看“电脑—手机”“手机—手机”“打通 NapCat—AstrBot”三种步骤。教程选项留在教程页内切换，不会跳回底部主导航。NapCat 可运行在电脑或另一部手机上，DSH 连接地址要填写 NapCat 所在设备的可达 IP；正向 WebSocket 监听端口默认示例为 3001、路径为 `/`、OneBot Token 必须一致。手机—手机教程包含 Termux 安装、NapCat 启动和登录、WebUI 区分、0.0.0.0 监听、手机 B IP 查找、Termux 后台保活及超时/拒绝/401/404 的排查。两台手机优先使用同一普通 Wi‑Fi；访客 Wi‑Fi、热点隔离、设备 IP 变化、VPN 和 Android 电池回收都可能导致断连。不同网络可用 Tailscale 私网，不要将 NapCat 端口映射到公网。连接还依赖 QQ 登录态、网络可达性、防火墙和 OneBot 配置；未看到连接状态“已连接”及实际收发回执前，不得声称已连通。可配置一个允许私聊联系人和最多 20 个群；群聊默认仅在桌宠被 @ 时回应，也可开启自由参与模式。群聊支持多张独立命名的人设卡，可手动新建，或导入 Character Card JSON、含角色卡数据的 PNG、TXT/MD；每次保存并连接 QQ 时可选择这次使用的人设，也可选“跟随桌宠默认人设”。群聊默认只用本机模型；可单独开启群聊 AstrBot Agent 插件模式，群消息会发送到远端，并以每个群独立的会话处理，不读取私聊记忆，也不执行手机工具。适用于由 Agent 调用的对话插件；依赖 OneBot 原生群事件的插件不适用。群聊文本不会执行手机点击或屏幕操作。桌宠文本与 QQ 私聊仍使用本机个人聊天记录；启用远端 AstrBot 智能体后，两者共用当前 AstrBot 会话，同一时间只发送一条远端聊天请求；本机记忆或人设快照变化时会在下一轮同步限长摘要到同一稳定会话，不上传整份本地聊天历史。AstrBot 原生 QQ 适配器使用另一种平台会话身份，仅设置相同 QQ 号或用户名不会自动合并两边历史。QQ 群聊默认不发送给 AstrBot；启用“群聊使用 AstrBot 插件”后，只将群消息和该群的独立上下文发送给远端 Agent，不与个人对话、其他群或个人长期记忆合并；每个活跃群最多留 36 条近期消息，空闲 30 分钟后由单次计时器自动触发、或关闭/变更 QQ 连接时调用手机本机聊天模型压缩成最多 6 条短摘要并清除原文。群聊摘要只记持续话题、有趣事件和待核实的新知识。没有可用本机聊天模型或摘要失败时，原始近期消息仍会清除。QQ 长连接仅在用户启用时运行；收起桌宠可保留连接，关闭个人 QQ 连接后停止。

## 插件与广告跳过规则
关键词：插件|扩展|写插件|安装插件|广告跳过|跳过广告|规则库|无障碍
普通插件在“功能中心 → 插件与扩展”管理。导入 JSON/ZIP 后先保持关闭，应用会做清单、入口、脚本大小、域名白名单和 DEX 文件检查；配置和 JavaScript 插件会请求已配置的聊天模型给兼容性建议。JavaScript 入口会在屏蔽联网、截图、点击、滑动、记忆读写的独立 WebView 沙箱里试跑；这只验证入口能否完成，不代表真实手机操作、网络或业务效果已经验证。问题可安全修复时会另存默认关闭的兼容副本，原插件不会被覆盖。原生 DEX 不会为了检查而执行；如果 ZIP 附带 Java 源码，才可尝试生成受限 JavaScript 副本，否则只能静态检查并给建议。AI 检查会把插件清单和受限长度的源码发送到当前聊天模型，不上传 DEX 二进制；未配置模型时只做本机检查。原生插件启用前必须在界面确认其会与桌宠同进程、拥有相同权限；发现本机结构阻断项时不允许启用。AI 生成 Java/DEX 插件时先出草稿，用户回复“装上”后才尝试编译/安装；插件安装失败必须报告真实错误。插件代码与普通插件配置不是广告跳过规则。广告跳过在“功能中心 → 广告跳过”，通过无障碍服务匹配可见、启用的文字、描述或资源 ID；内置规则只认明确的广告跳过文案，普通“关闭”等按钮不会因页面出现广告二字就被误点。点击后需观察到跳过按钮消失且界面变化，才记为一次成功；系统只接受了点击但页面没变时不会增加成功次数。重复无障碍事件和前端状态同步也不会重复累加。可以导入规则 JSON、测试规则、查看统计和日志；没有无障碍权限、规则未命中或控件不可点击时不会跳过，严禁把点赞、关注、购买等当作跳过动作。

## 角色、性格、关系与记忆
关键词：人设|角色|性格|亲密度|记忆图谱|记忆|回忆|关系|日记|经历
“功能中心 → 角色与记忆/记忆图谱/我们的关系”可查看和维护人设、用户资料、性格变化、亲密度、聊天记忆、共同经历和日记。记忆页的“打开识海”或首页桌宠卡片右上角的“识海”按钮进入本地视图：只读现有记忆和本机已观察经历，不改数据库、不联网；最多显示 8,000 条有效、未过期且非机密记忆、10 条以内经屏幕读取确认的短心得，并绘制最多 14,400 条真实关联。超过展示上限的记忆仍保存在本机；识海统计显示展示数与符合条件总数。未发生、失败或未经确认的计划不会作为共同经历；带手机号、邮箱、证件号、银行卡号或密码/令牌线索的心得会过滤。每条记忆和经历对应一颗可点选的发光气泡；目前支持事实、偏好、人物、项目、事件、计划、惦记、承诺、印象、心情、日常、健康、地点、学习、兴趣、目标、经历 17 类，同类使用固定颜色，图例会显示当前类别数量。只有 Java 返回的共同标签或原文关键词关系才画连线，不按时间相邻或类别伪造关系，也不代表模型验证过语义；相连节点会按真实关系轻微聚拢。小视图嵌在识海卡片中，点“放大视图”可铺满内容区；支持单指拖动进行完整球面旋转、双指缩放、按钮缩放和全景复位，自动旋转默认关闭以减少耗电。点选节点会显示记忆正文、来源和标签；点选后节点与真实关联会高亮，并短暂显示沿关系线移动的能量光点。源码优先用本地 Three.js 以批量粒子点与线段绘制 3D 气泡网络；WebGL 不可用时用缓存发光贴图和合并线条的轻量 Canvas 2D 兼容图，且仍只展示真实关系。识海打开时 Live2D 降低到 15 FPS；记忆始终保存在本机，不上传。开场全屏静音播放包内 MIT dsh-video-skin 短片一次、不循环，并在片尾前约 1.7 秒裁停；星流动画与本地记忆读取同时进行，约 5.9 秒内汇聚成八组分类星团。播放视频时，星流画布位于视频下层并调暗，避免遮挡动画主体；最短约 6.7 秒，数据就绪后淡出，最长约 16 秒后展开，不可点击跳过。视频无法播放时仍播放本地分类星团粒子动画。使用的开源项目、MIT 许可和归属见 app/src/main/assets/licenses/THIRD-PARTY-NOTICES.txt。聊天记录及本地索引支持按话题回忆；标注为印象或日记的推断不等同用户原话。显式要求记住的内容会写入本地长期记忆。日记按经历重要性判断生成，不代表每次聊天都会写日记。

## 桌宠、动作与主动陪伴
关键词：桌宠|动作|陪伴|主动互动|自由行动|气泡|双击|长按|悬浮窗
桌宠浮窗由前台服务维护，可拖动、长按打开外观/显示控制；“动作”页可预览和触发动作，“陪伴/主动记录”相关设置控制主动互动策略。桌宠触摸命中范围按站姿身体透明轮廓计算，并随桌宠大小、镜像方向和皮肤同步；挥手、跳跃等动作仍照常显示，但伸出身体的动作画面不会扩大触摸范围。Android 13 及以上还会让轮廓外的触摸交给下层应用；旧系统至少不会把身体以外的点击当作桌宠点击。自由行动默认关闭；用户开启后不依赖普通主动开口开关，但需无障碍、可用 AI 且聊天类主动行为未关闭。手机须亮屏、解锁并连续 10 分钟无触控，且未处于总静音、夜间、专注、聊天或听语音状态；开始前先显示目的地提示。应用列表勾选后会限制到勾选项；全部不勾选表示允许所有通过安全筛选的应用，系统、通讯、财务和购物类应用不允许。她可依据刚读取的屏幕做滑动、返回或点击普通导航文字，不会发送消息、点赞、评论、发布、购买、支付、删除、登录或改设置。屏幕文字及必要截图会发送给用户配置的 AI 服务，只保存有实际观察依据的简短心得，不保存整屏内容。行动期间临时保持屏幕点亮，增加耗电和 AI 用量；默认每 60 秒观察一次，可调 30–120 秒。用户触控、切换应用、锁屏/熄屏、关闭自由行动、双击桌宠或说“停下来”都会结束；若无法可靠读取页面也会停止。普通主动提出的浏览/阅读邀请仍需用户同意。

## 实现结构（用户问“功能怎么实现”时使用）
关键词：实现|原理|代码|架构|怎么做|工作流程|原理是什么
界面由 Android 原生 Activity 承载 WebView；前端调用 `MainAct.Bridge`，由 `MainAct.dispatch` 分发至 Java 模块。聊天提示词、历史与记忆编排在 `Brain`，模型网络请求在 `Ai`；本机数据由 `Sg` 存储。读书在 `Books`，无障碍能力在 `A11y`，插件编译/运行由 `PluginGen`、`PluginDexCompiler`、`DexPlugins` 负责。回答原理时先说用户能理解的步骤；若没有证据，不要声称某一实现细节已在设备验证。

## 她说过的话与即兴记忆
关键词：她说过|以前说过|原话|即兴说过|主动说过|忘记自己说的话
桌宠实际发出的聊天回复（包括标记为即兴的主动话语）会另建精简索引，保存在应用私有 S-G 目录，最多 320 条、每条最多 240 字；升级后会从最近的本地聊天记录迁移她自己的回复，不复制用户原话。用户问她以前说过什么时，按话题和日期取最多 3 条实际原话；没有命中就应坦白找不到，不能编造或把用户说过的话冒充成她的。主动聊天会参考最近几句，减少即兴话语重复。索引只在本机保存，匹配到的少量片段按当前模型的正常聊天规则作为上下文发送；“清空全部记忆”会同时清除此索引，聊天记录本身依照聊天页的清理操作管理。

## 桌宠动作完整显示与触摸范围
关键词：动作被切|动作显示不全|桌宠触摸范围|透明边|点击范围
